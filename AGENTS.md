## 📌 Проект

**Название:** Раскатка адресов  
**Цель:** Автоматизация сбора, нормализации, валидации и распределения адресных данных с интеграцией Яндекс Карт и Google Sheets.

## 🧩 Модули (вкладки)

| Вкладка        | Функция |
|----------------|---------|
| **Раскатка** | Случайный подбор адресов из листов `Rolling` и `Parser` по фильтрам город/регион/комментарий |
| **Сбор дополнений** | Пакетный сбор транслита, координат, индексов через Яндекс Карты |
| **Дополнение таблицы** | Пошаговый режим: поиск на карте → капча/выбор здания → нормализация → сохранение в `Parser` |

## ⚙️ Запуск

1. `Установщик Раскатки.bat` — создаёт `.venv`, устанавливает deps, качает Firefox ≥140, geckodriver v0.34.0 и JSON key.
2. `utils/run.bat` — запускает `code.py` через `.venv`.
3. Открывается UI на `http://localhost:7000` с splash-экраном.

### Ключевые пути в `code.py`

## ⚠️ Ключевые решения и ограничения

| Решение / Проблема | Решение |
|--------------------|---------|
| Консоль CMD «прыгала» при старте | Скриттинг через `ctypes.ShowWindow(hwnd, 0)` + неблокирующий `eel.start(block=False)` |
| `print()` не попадал в UI | Обёртка `EelLogger`, перенаправляющая `sys.stdout/stderr` через `eel.addLog` |
| Старые абсолютные пути ломались при перемещении | Перешли на `os.path.dirname(os.path.abspath(__file__))` |
| Ключ Google API был в открытом виде | Перенесён в `.gitignore`, инсталлятор генерирует JSON при установке |
| Лист «База» → «Раскатка адрессов» | Переименование таблицы в коде |
| Нет документации проекта | Добавлены `README.md` + `AGENTS.md` |

# «Раскатка адресов» — Инструкция пользователя и документация

Десктопное приложение для автоматизации сбора, нормализации, валидации и распределения адресных данных с интеграцией Яндекс Карт и Google Sheets.

---

## 🎯 Назначение программы

Программа решает три основные задачи работы с адресами:

| Вкладка | Что делает |
|---------|------------|
| **Раскатка** | Случайный подбор адресов из базы по фильтрам (город, регион, комментарий) |
| **Сбор дополнений** | Пакетное получение координат, индексов, транслита городов для списка адресов |
| **Дополнение таблицы** | Пошаговое добавление новых адресов через выбор на карте |

---

## 🖥 Быстрый старт

### 1. Установка (один раз)
Запустите **`Установщик Раскатки.bat`** — он автоматически:
- Проверит/установит Python 3.11+
- Установит Firefox 140+ и geckodriver
- Создаст виртуальное окружение `.venv`
- Установит все Python-зависимости
- Скачает ключ Google Service Account (нужен доступ к интернету)

### 2. Запуск
Два способа:
- **`Приложение.exe`** — ярлык на рабочем столе / в папке
- **`utils\run.bat`** — запуск через консоль

После запуска откроется окно браузера на `http://localhost:7000` с экраном загрузки (проверка Google API, подключение к таблицам).

---

## 📋 Подготовка Google Таблицы

Перед работой убедитесь, что у вас есть доступ к таблице **«Раскатка адрессов»** с двумя листами:

| Лист | Назначение | Важные столбцы |
|------|------------|----------------|
| `Rolling` | Начальная база адресов (только чтение) | A:Город, B:Транслит, C:Тип НП, D:Регион, E:Адрес, F:Полный адрес, G:Координаты, H:Индекс, I:Комментарий |
| `Parser` | Накопленная рабочая база (чтение + запись) | Та же структура |

> **Важно:** Дубликаты проверяются по столбцу **E (Адрес)**. Одинаковые адреса не запишутся дважды.

## 🗂 Работа с вкладками

### Вкладка 1: «Раскатка» — подбор адресов из базы

**Входные данные (слева):**
- **Город** — список городов (по одному в строке)
- **Регион** — список регионов (по одному в строке, может быть пустым)
- **Комментарий** — фильтр по комментарию (например, «метро», «ТЦ»), пустая строка = без фильтра
- **Выбор базы** — `Rolling`, `Parser` или оба одновременно

**Запуск:** кнопка **«Начать»**

**Результат (таблица справа):**
| Колонка | Описание |
|---------|----------|
| Адрес | Нормализованный адрес (ул., пр. и т.д.) |
| Транслит | Транслитерация названия города |
| Регион | Регион (область/край/республика) |
| Координаты | Широта, долгота из Яндекс Карт |
| Индекс | Почтовый индекс |

**Кнопки под таблицей:**
- **Адрес / Транслит / Регион / Координаты / Индекс** — копируют весь столбец в буфер обмена (с пустыми строками, по одной на Enter)
- **Скопировать всю таблицу** — копирует таблицу целиком в формате **TSV** (табуляция между колонками) — удобно для вставки в Google Sheets / Excel

**Ошибки:** выводятся в поле «Ошибки/Не найденные» под таблицей (города, по которым ничего не нашлось).

---

### Вкладка 2: «Сбор дополнений» — пакетное заполнение данных

**Подготовка:** заполните три текстовые области слева (по одной записи в строке):
- **Адрес** — полные адреса
- **Город** — города (обязательно)
- **Регион** — регионы (желательно)

Количество строк во всех трёх полях должно совпадать.

**Запуск:** кнопка **«Начать»**

**Что происходит:** программа открывает Firefox, по очереди ищет каждый адрес на Яндекс Картах и извлекает:
- Транслит города
- Координаты (широта, долгота)
- Регион (нормализованный)
- Почтовый индекс

**Результат:** заполняются правые поля (Транслит, Координаты, Регион, Индекс) — строки соответствуют входным данным. Ошибки собираются в поле «Ошибки/Не найденные».

> ⚠️ Процесс может быть долгим (несколько секунд на адрес). Не закрывайте окно браузера.

---

### Вкладка 3: «Дополнение таблицы» — добавление новых адресов

**Режим:** пошаговый с ручным подтверждением каждого адреса.

**Шаг 1. Ввод списка городов/регионов** (левая панель):
- Города — по одному в строке
- Регионы — по одному в строке (можно оставить пустым)
- Тип поиска: «Стандартный» (город + регион) или «Пользовательский» (например, «метро в Москве»)

**Шаг 2. Поиск:** нажмите **«Начать»** → откроется Яндекс Карты с первым городом.

**Шаг 3. Выбор здания:** на карте кликните нужное здание/объект.

**Шаг 4. Запись данных:** нажмите **«Записать»** (стало доступно после выбора).
- Программа нормализует адрес (приводит «Улица» → «ул.», «Проспект» → «пр.» и т.д.)
- Определяет тип НП (город/посёлок/деревня) и название города
- Подставляет регион из справочника `REGIONAL_CAPITALS` для областных центров
- Извлекает координаты и почтовый индекс
- **Жёлтая рамка** у полей = предупреждение (нужна ручная проверка)

**Шаг 5. Правка (при необходимости):** отредактируйте поля вручную, если нормализация ошиблась.

**Шаг 6. Сохранение:** нажмите **«Сохранить»** → строка добавится в лист `Parser` (проверка на дубликат по адресу).

**Шаг 7. Следующий:** нажмите **«Следующий»** для перехода к следующему городу.

## ⌨ Горячие клавиши и советы

| Действие | Как сделать |
|----------|-------------|
| Копировать столбец | Клик по кнопке под таблицей («Адрес», «Транслит» и т.д.) |

## 🔧 Настройки и тонкости

### Нормализация регионов
Яндекс Карты возвращают длинные названия регионов. Программа автоматически сокращает:
- Кемеровская область — Кузбасс → **Кемеровская область**
- Республика Северная Осетия — Алания → **Республика Северная Осетия**
- Республика Татарстан (Татарстан) → **Республика Татарстан**
- Чувашская Республика — Чувашия → **Чувашская Республика**
- Республика Саха (Якутия) → **Республика Саха**
- Ханты-Мансийский автономный округ — Югра → **Ханты-Мансийский автономный округ**

### Справочник региональных центров
Для городов-столиц регионов (Москва, Санкт-Петербург, Екатеринбург, Казань и др.) регион определяется автоматически из встроенного словаря `REGIONAL_CAPITALS` в `utils/code.py`.

### Обновления
При старте программа проверяет версию на GitHub. Если есть новая — покажет диалог с кнопками «Обновить» / «Пропустить». Обновление скачивается как ZIP, распаковывается и приложение перезапускается само.

## 🐛 Известные ограничения

| Ограничение | Обходное решение |
|-------------|------------------|
| Нужен VPN/доступ к Google API и Яндекс Картам | Включите VPN перед запуском |
| Firefox должен быть версии 140+ | Установщик качает нужную версию сам |
| При больших объёмах «Сбор дополнений» может упасть по таймауту | Разбивайте на партии по 50-100 адресов |
| Капча на Яндекс Картах | В «Дополнении таблицы» решается вручную оператором |

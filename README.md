# Проект «Раскатка адресов»

Десктопное приложение для автоматизации сбора, нормализации, валидации и распределения адресных данных с интеграцией Яндекс Карт и Google Sheets.

---

## 🛠 Стек технологий

* **Backend / Скрипты:** Python 3.11+
  * `eel` — локальный веб-сервер и мост между Python и браузерным UI.
  * `selenium` + `geckodriver` (Firefox) — автоматизация взаимодействия с Яндекс Картами.
  * `gspread` + Google Sheets API v4 (Service Account) — работа с базой данных в таблицах.
  * `transliterate`, `requests`, `ctypes`, `re`.
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS).
* **Скрипты развертывания:** PowerShell / Batch (`Установщик Раскатки.bat`, `utils/run.bat`).

## 🚀 Основные модули и функционал

### 1. Модуль «Раскатка» (`raskatka-tool`)
* **Назначение:** Случайный подбор адресов из накопленной базы по фильтрам (Город, Регион, Комментарий).
* **Выбор источника данных:**
  * Лист `Rolling` (начальная база);
  * Лист `Parser` (общая накопленная база);
  * Оба листа одновременно.
* **Результат:** Формирование списков адресов, транслитераций, регионов, координат и индексов, а также отслеживание ненайденных позиций.

### 2. Модуль «Сбор дополнений» (`sbor-tool`)
* **Назначение:** Пакетное заполнение недостающей информации по уже имеющимся адресам.
* **Процесс:**
  1. Принимает списки адресов, городов и регионов.
  2. В автоматическом режиме открывает Яндекс Карты через Firefox.
  3. Извлекает: транслит города, точные координаты, регион, почтовый индекс.
  4. Формирует отчёт об ошибках/ненайденных объектах.

### 3. Модуль «Дополнение таблицы» (`search-tool`)
* **Назначение:** Полуавтоматический режим пополнения базы новыми объектами.
* **Процесс:**
  1. Поиск города/региона или целевого запроса («метро», «тц» и т.д.).
  2. Оператор выбирает здание на карте.
  3. Нажатие «Записать» (`capture_map_data`):
     * Нормализация названия улицы (приведение к `ул.`, `пр.` и перенос типа в начало).
     * Определение типа населенного пункта и названия города (с защитой от промежуточных районов).
     * Проверка справочника региональных центров (`REGIONAL_CAPITALS`).
     * Извлечение координат и почтового индекса.
     * Подсветка предупреждений (желтая рамка при неоднозначностях).
  4. Нажатие «Сохранить» (`save_captured_data`):
     * Проверка на дубликаты в листах `Rolling` и `Parser`.
     * Добавление строки в лист `Parser`.

## ⚙️ Установка и запуск

1. **Автоматическая установка:** Запустить `Установщик Раскатки.bat` — скрипт проверит наличие Python и Firefox (v140+), создаст `.venv`, установит зависимости и скачает необходимые утилиты.
2. **Запуск приложения:**
   * Через ярлык `Приложение.exe` или `utils/run.bat`.
   * При старте открывается стартовый оверлей, где отображается статус подключения к Google API и готовность систем.
